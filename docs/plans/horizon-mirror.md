# Horizon: walk to the object

November 8, 2026. This replaces the earlier mirror and tape design. The historical filename remains for existing links.

## The place

One real closed curved space, with seven roads to one object and 118 tumbling pieces drawn from the game's own models. Walking away from an object makes it grow; approaching it changes its apparent size until it reaches its real size nearby. Sarah, Lyle, the daisy and the ant are the only possible occupants. There is no mirror, Horizon bust or eye exchange. The gallery's separate bust and eye history remain.

## Arrival and departure

Keep the existing drive, repeated street, telephone encounters and optional pub. Horizon interrupts at the street's far edge, reached by walking. It uses the existing light transition when effects are enabled and remains available without visual effects. The new scene owns a local body; the existing Source reducer owns the two roads.

The truth is always given. An earned condition opens an additional tower offer. Waiting never decides. A physical departure toward the tower accepts; walking onward chooses the chapel. The route is saved before the transition. Reload restores unfinished local progress or completes a durable road decision.

## Bargain and clock

The existing bargain is preserved: cathedral losses one and two return to the same occupant, with the chapel closed. Walking elsewhere on a return cannot decline. Taking the tower path resumes the actual cathedral fight. The third loss reaches tower-lost. The reducer and its durable event names remain unchanged.

Source freezes the night clock. The existing exit rule sets 05:38. Reduce Dread keeps all occupants and softens unkind presentation rather than removing a figure.

## Implementation

- `horizon-approach.js`: curved space, occupants, seven roads and real debris catalog.
- `horizon-approach-record.js`: pure evidence reader and fallback.
- `horizon-approach-dialogue.js`: truths, offer, petal and return lines.
- `horizon-approach-scene.js`: local movement, waiting, arrival, petals, choices and return.
- Approach renderer/model/frame modules and the shared curved-space prop transform.
- Native host in `main.js`: loading, light transition, voices, save, actual route callbacks and recovery.
- Runtime bridge: recognition, decision and the existing road-exit method. No eye evidence is fabricated.

The old splat tape, scrubbed score, dial machine, Horizon portrait and their baked assets are retired after the new live roads and return pass. Camera math and physical-decay shader text used by other Source scenes live in neutral renderer modules.

## Evidence and remaining art decisions

Source tests cover evidence, fallback, waiting, physical decisions, reload and the reducer bridge. Developer-assisted browser routes cover both physical departures and the cathedral return. These are not unbriefed player validation or packaged native acceptance.

Open art decisions remain explicit: distant sheet music can read as blank paper; Sarah and Lyle use the available similar character models; hubcaps can read as white discs; there is no complete chapel exterior model; self-recursion is not implemented. Do not invent replacement assets or present those decisions as approved.
