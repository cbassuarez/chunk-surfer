Playback diagnosis and proposed KDE path

The current player abandons MP4 playback after a 1.2-second first-frame timeout, a 400 ms stall or a media error. Its old fallback animated a single poster across the crop; readiness also translated the complete video element. Both CSS translations are now removed. Failure shows a stationary still and never holds readiness.

The existing exported startup motion also adds large independent X offsets and yaw changes. Correcting only CSS cannot repair those authored frames. The candidate instead integrates a rear-axle path and derives each tyre’s steering and rotation from it.

Implemented package path: use a pre-rendered transparent PNG atlas as the primary player, with time-based frame selection and a static still on decoding failure. It needs neither GStreamer/H.264 nor a fresh startup WebGL context. The 84 × 128 px atlas preserves roughly 24 fps, is capped at 300 KiB encoded, and decodes with its poster to 5.56 MiB within a 6 MiB cap. Export and resource checks pass; packaged KDE acceptance is tracked separately. No claim of a proven codec failure on tvplex is made from the fallback code alone.

Dock inspection, shared clock and lifecycle proposal

The existing native Dock uses a custom NSDockTile view, an 84-frame atlas, a 24 Hz timer and the shared Rust Instant epoch. It begins during Tauri setup, skips overdue frames, then releases the atlas for a static icon. The closed-app Dock plug-in is static. The bridge now supplies versioned elapsed time and an idempotent readiness timestamp to the webview.

Implemented bridge: native setup owns one monotonic launch epoch, motion version and readiness event. A Tauri command returns elapsed uptime; the webview estimates round-trip uncertainty with performance.now(), joins the matching frame and resamples on focus. It never restarts the maneuver when the webview arrives late. OS launch bounce precedes custom tile setup and cannot be made part of a frame-accurate contract. AppKit timer / compositor scheduling also prevents a promise of exact displayed-frame synchronization.
